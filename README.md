# Суть — поиск по нескольким поисковикам с выжимкой главного

Приложение на Python + Kivy. Вводите запрос — оно параллельно спрашивает
DuckDuckGo, Bing, Brave, Mojeek и Wikipedia, объединяет выдачу без дублей,
читает найденные сайты и показывает внутри приложения:

1. **Суть** — несколько ключевых предложений со всех сайтов (приоритет у фактов,
   которые повторяются на разных источниках), с номерами источников;
2. **Источники** — карточки с 2 главными предложениями с каждого сайта;
   нажатие на заголовок открывает сайт в браузере.

## Запуск на компьютере (проверка)

    pip install kivy requests beautifulsoup4
    python main.py            # окно приложения
    python search_core.py "ваш запрос"   # то же в консоли, без интерфейса

## Сборка APK для Android

Нужен Linux или WSL:

    pip install buildozer cython
    buildozer android debug       # первый раз долго: скачивает SDK/NDK
    # готовый файл: bin/sut-0.1-*-debug.apk

Установите APK на телефон (разрешите установку из неизвестных источников).
Для iPhone используют kivy-ios, потребуется Mac и Xcode.

## Как устроено

- `search_core.py` — поисковики, загрузка страниц, извлечение текста, выжимка.
  Выжимка экстрактивная: предложения оцениваются по частоте слов, совпадению
  с запросом и по тому, на скольких сайтах встречаются; близкие по смыслу
  дубли отбрасываются. Нейросети и ключи API не нужны.
- `main.py` — интерфейс Kivy; поиск идёт в фоновом потоке.

## Ограничения

- Google и Яндекс не включены: они блокируют автоматические запросы капчей.
  Чтобы получать и их выдачу, можно указать адрес SearXNG-инстанса
  (параметр `searx_url` в `run_search`, поисковик «SearXNG» в `ENGINES`).
- Поисковики без API отдают HTML, и при смене вёрстки селекторы в
  `search_core.py` придётся поправить. Недоступные поисковики приложение
  пропускает и показывает их названия в строке статуса.
- Выжимка — отбор готовых предложений, а не пересказ; для настоящего
  пересказа можно подключить языковую модель по API.
